O hře

The Legend of Zelda: The Minish Cap (Capcom/Nintendo, 2004) je posledním 2D Zelda příběhem před přechodem série na 3D. Link dostane od klobouku Ezlo schopnost zmenšovat se a procházet svět z hmyzí perspektivy. Objevuje kmen Piccoru, sbírá Kámen osudu (Kinstones), a čelí černokněžníkovi Vaatimu.

Jak na překlad

Tady byla cesta nejčistší ze všech. Repo zeldaret/tmc už má překlady v JSON formátu (`translations/USA.json`) — pole 80 skupin stringů se `\n`, `{Var:N}`, `{Color:X}` markery. Stačí přepsat anglické stringy na české, spustit `tmc_strings` (kompilátor textu) a získat novou ROM.

Náš workflow:

  1. split_usa.py — rozdělí 2909 překladatelných stringů do 8 chunků
  2. 8 paralelních agentů překládá — každý svůj chunk
  3. merge_usa.py — sjednotí zpět do USA.json
  4. Auto-transliterace pro znaky mimo font (Turkish `ı`, české diakritiky)
  5. tmc_strings → USA.bin → linkuje se do ROM

Tvrdá omezení

  • Toolchain pinning — tmc decomp byte-matchuje jen s přesně pinnutou verzí devkitARM, kterou nemáme. Náš build s devkitARM r66 je 25 % byte-divergentní od originálu. Postavená ROM je označená experimental, protože její chování jsme nemohli plně otestovat.
  • Bez diakritiky (v0.1) — háčky a čárky převedeny na ASCII (á→a, č→c, atd.). Font by některé podporoval, ale zatím jistota.
  • API session limit zastavil 2 z 8 agentů → 74 % pokrytí. Zbylé texty zůstanou anglicky (silent fallback).
